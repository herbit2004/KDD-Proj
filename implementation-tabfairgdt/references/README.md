# References

1. **Main paper:** Emmanouil Panagiotou, Benoît Ronval, Arjun Roy, Ludwig Bothmann, Bernd Bischl, Siegfried Nijssen, and Eirini Ntoutsi. “TABFAIRGDT: A Fast Fair Tabular Data Generator using Autoregressive Decision Trees.” *IEEE International Conference on Data Mining (ICDM)*, 2025. [arXiv record](https://arxiv.org/abs/2509.19927) · [PDF](https://arxiv.org/pdf/2509.19927). Local file: `local-pdf/2509.19927v1.pdf` (10 pages). The arXiv record states [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the same PDF is available in `public-pdf/` with attribution to the authors.
2. **Generative baseline and motivation:** Depeng Xu, Shuhan Yuan, Lu Zhang, and Xintao Wu. “FairGAN: Fairness-aware Generative Adversarial Networks.” *IEEE International Conference on Big Data*, pp. 570–575, 2018. [arXiv record](https://arxiv.org/abs/1805.11202) · [PDF](https://arxiv.org/pdf/1805.11202). Local file: `local-pdf/1805.11202.pdf` (11 pages; arXiv v1). It connects fair synthetic data with downstream classifier behavior. The available arXiv license does not establish public redistribution rights.
3. **Imbalance evidence:** Emmanouil Panagiotou, Arjun Roy, and Eirini Ntoutsi. “Synthetic Tabular Data Generation for Class Imbalance and Fairness: A Comparative Study.” arXiv:2409.05215, v1, 2024. [Record](https://arxiv.org/abs/2409.05215) · [PDF](https://arxiv.org/pdf/2409.05215). Local file: `local-pdf/2409.05215.pdf` (15 pages). The paper concerns joint class/group imbalance, relevant to the generator's evaluation. No public redistribution license was confirmed.
4. **Fairness definition:** Mahed Abroshan, Andrew Elliott, and Mohammad Mahdi Khalili. “Imposing Fairness Constraints in Synthetic Data Generation.” *Proceedings of AISTATS*, PMLR 238:2269–2277, 2024. [Proceedings record](https://proceedings.mlr.press/v238/abroshan24a.html) · [PDF](https://proceedings.mlr.press/v238/abroshan24a/abroshan24a.pdf). Local file: `local-pdf/abroshan24a.pdf` (22-page proceedings PDF with appendices). It distinguishes fairness conditions at generation and downstream evaluation. Public redistribution terms for this exact file were not checked.

**Data and implementation:** [Author GitHub repository](https://github.com/Panagiotou/TABFAIRGDT) (MIT license; includes example, experiment and evaluation scripts). The primary benchmark is [UCI Adult](https://archive.ics.uci.edu/dataset/2/adult); the repository's loader and the UCI record provide the data entry points. The code example sets `lamda=0` for no fairness adjustment and accepts larger values at fit time.
