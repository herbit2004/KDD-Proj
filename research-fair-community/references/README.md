2. **相关研究：** Christos Gkartzios、Evaggelia Pitoura 与 Panayiotis Tsaparas. “Fair Network Communities through Group Modularity.” *The Web Conference (WWW)*，2025。[作者 PDF](https://www.cse.uoi.gr/~tsap/publications/Gkartzios-WWW2025.pdf)。本地文件：`local-pdf/Gkartzios-WWW2025.pdf`（12 页）。PDF 标明 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；公开目录 `public-pdf/` 保存了署名副本。
3. **相关研究：** Georgios Panayiotou、Anand Mathew Muthukulam Simon、Matteo Magnani 与 Ece Calikus. “MOUFLON: Multi-group Modularity-based Fairness-aware Community Detection.” *Data Mining and Knowledge Discovery*，第 40 卷，文章 92，2026。[出版商页面与 PDF](https://link.springer.com/article/10.1007/s10618-026-01260-5)，DOI：[10.1007/s10618-026-01260-5](https://doi.org/10.1007/s10618-026-01260-5)。本地文件：`local-pdf/s10618-026-01260-5.pdf`（43 页）。在确认该出版版本的许可与署名要求前，PDF 仅保存在本地。
4. **深度模块度基础：** Anton Tsitsulin、John Palowitch、Bryan Perozzi 与 Emmanuel Müller. “Graph Clustering with Graph Neural Networks.” *Journal of Machine Learning Research*，24(127):1–21，2023。[期刊页面](https://www.jmlr.org/papers/v24/20-998.html) · [PDF](https://www.jmlr.org/papers/volume24/20-998/20-998.pdf)。本地文件：`local-pdf/dmon-jmlr23.pdf`（21 页）。该文提出 DMoN；未确认该 PDF 的公开再分发许可。
