# References

1. **Main paper:** Han Zhang and Dongfang Zhao. “RAE: A Neural Network Dimensionality Reduction Method for Nearest Neighbors Preservation in Vector Search.” *KDD*, 2026, as identified by the [author's faculty publication list](https://faculty.washington.edu/dzhao/), [author repository](https://github.com/explorerZH/RAE-KDD2026), and [COMP5331 suggested-topic list](https://canvas.ust.hk/courses/72132/pages/project-suggestedtopics). [Available arXiv v1 record](https://arxiv.org/abs/2509.25839) · [PDF](https://arxiv.org/pdf/2509.25839). Local file: `local-pdf/2509.25839v1.pdf` (13 pages). This available PDF and the Canvas upload still carry an **ICLR 2026 header**; they are an earlier/version-conflicted manuscript rather than proof that the KDD listing is wrong. The author repository's BibTeX DOI is a placeholder, so no DOI is asserted here. arXiv's non-exclusive distribution statement does not authorize public PDF redistribution.
