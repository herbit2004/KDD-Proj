# 参考文献与资源

1. **主论文：** Han Zhang 与 Dongfang Zhao. “RAE: A Neural Network Dimensionality Reduction Method for Nearest Neighbors Preservation in Vector Search.” [作者主页](https://faculty.washington.edu/dzhao/)、[作者仓库](https://github.com/explorerZH/RAE-KDD2026)和 [COMP5331 推荐清单](https://canvas.ust.hk/courses/72132/pages/project-suggestedtopics)均将其列为 *KDD 2026*。[可获取的 arXiv 第 1 版页面](https://arxiv.org/abs/2509.25839) · [PDF](https://arxiv.org/pdf/2509.25839)。本地文件：`local-pdf/2509.25839v1.pdf`（13 页）。该稿与 Canvas PDF 首页仍保留 **ICLR 2026** 标头；作者仓库中的 BibTeX DOI 为占位值，因此此处未列 DOI。arXiv 页面未标明公开再分发许可。
2. **相关研究：** Leland McInnes、John Healy 与 James Melville. “UMAP: Uniform Manifold Approximation and Projection for Dimension Reduction.” arXiv:1802.03426，首次发布于 2018 年；本地保存的第 3 版 PDF 日期为 2020 年。[arXiv 页面](https://arxiv.org/abs/1802.03426) · [PDF](https://arxiv.org/pdf/1802.03426)。本地文件：`local-pdf/1802.03426v3.pdf`（63 页）。未确认该 PDF 的公开再分发许可。
3. **局部尺度基础：** Lihi Zelnik-Manor 与 Pietro Perona. “Self-Tuning Spectral Clustering.” *Advances in Neural Information Processing Systems*，第 17 卷，2004。[会议 PDF](https://proceedings.neurips.cc/paper/2004/file/40173ea48d9567f1f393b20c855bb40b-Paper.pdf)。本地文件：`local-pdf/self-tuning-spectral-clustering.pdf`（8 页）。该文提出局部尺度自适应方法；未确认公开再分发许可。
4. **检索目标相关研究：** Jiuzhou Fu 与 Dongfang Zhao. “QPAD: Quantile-Preserving Approximate Dimension Reduction for Nearest Neighbors Preservation in High-Dimensional Vector Search.” arXiv:2504.16335，第 2 版，2025。[arXiv 页面](https://arxiv.org/abs/2504.16335) · [PDF](https://arxiv.org/pdf/2504.16335)。本地文件：`local-pdf/2504.16335.pdf`（14 页）。该文同样以向量检索中的近邻保留为目标；未确认公开再分发许可。

**数据与代码：** [RAE 作者仓库](https://github.com/explorerZH/RAE-KDD2026)采用 MIT 许可，含训练与基线脚本。数据加载器要求五种指定数据集与嵌入的预计算文件格式。拟使用的小型真实向量数据为 [UCI Optical Recognition of Handwritten Digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits)：5,620 个样本、64 个数值特征，提供训练与测试文件，DOI：[10.24432/C50P49](https://doi.org/10.24432/C50P49)，数据许可为 CC BY 4.0。将其用于 RAE 需编写数据格式适配程序。
