# References

1. **Main paper:** Han Zhang and Dongfang Zhao. “RAE: A Neural Network Dimensionality Reduction Method for Nearest Neighbors Preservation in Vector Search.” Listed as *KDD 2026* by the [author's faculty page](https://faculty.washington.edu/dzhao/), [author repository](https://github.com/explorerZH/RAE-KDD2026), and [COMP5331 suggested topics](https://canvas.ust.hk/courses/72132/pages/project-suggestedtopics). [Available arXiv v1 record](https://arxiv.org/abs/2509.25839) · [PDF](https://arxiv.org/pdf/2509.25839). Local file: `local-pdf/2509.25839v1.pdf` (13 pages). The accessible manuscript and the Canvas PDF carry an **ICLR 2026 header**. The author repository's BibTeX has a placeholder DOI; no DOI is listed here. The arXiv distribution terms do not state permission to redistribute this PDF publicly.
2. **Related reading:** Leland McInnes, John Healy, and James Melville. “UMAP: Uniform Manifold Approximation and Projection for Dimension Reduction.” arXiv:1802.03426, first posted 2018; downloaded v3 PDF dated 2020. [Record](https://arxiv.org/abs/1802.03426) · [PDF](https://arxiv.org/pdf/1802.03426). Local file: `local-pdf/1802.03426v3.pdf` (63 pages). No explicit redistribution permission was verified; use the source link for public access.

[Proceedings PDF](https://proceedings.neurips.cc/paper/2004/file/40173ea48d9567f1f393b20c855bb40b-Paper.pdf). Local file: `local-pdf/self-tuning-spectral-clustering.pdf` (8 pages). Public redistribution permission was not verified.
4. **Retrieval-oriented neighboring work:** Jiuzhou Fu and Dongfang Zhao. “QPAD: Quantile-Preserving Approximate Dimension Reduction for Nearest Neighbors Preservation in High-Dimensional Vector Search.” arXiv:2504.16335, v2, 2025. [Record](https://arxiv.org/abs/2504.16335) · [PDF](https://arxiv.org/pdf/2504.16335). Local file: `local-pdf/2504.16335.pdf` (14 pages). Public redistribution permission was not verified.

**Data and implementation:** [RAE author repository](https://github.com/explorerZH/RAE-KDD2026), MIT license, with training and baseline code. Its loader names five dataset/embedding combinations and requires precomputed files in prescribed formats. The planned smaller real-vector dataset is [UCI Optical Recognition of Handwritten Digits](https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits): 5,620 examples, 64 numerical features, published training/test files, DOI [10.24432/C50P49](https://doi.org/10.24432/C50P49), CC BY 4.0. An adapter is required to use it with RAE's loader.
