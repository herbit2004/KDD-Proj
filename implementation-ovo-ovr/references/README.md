# 参考文献与资源

1. **主论文：** Kuan-Ting Chen 与 Chih-Jen Lin. “Revisiting One-Versus-One and One-Versus-Rest: Insights into Imbalanced Multi-class Classification.” *IEEE International Conference on Data Mining (ICDM)*，2025。[作者论文与代码页面](https://www.csie.ntu.edu.tw/~cjlin/papers/ovo-ovr/) · [论文 PDF](https://www.csie.ntu.edu.tw/~cjlin/papers/ovo-ovr/OVO-OVR.pdf)。本地文件：`local-pdf/OVO-OVR.pdf`（9 页）。作者提供的 PDF 未标明公开再分发许可，因此公开仓库使用来源链接。
2. **方法比较：** Chih-Wei Hsu 与 Chih-Jen Lin. “A Comparison of Methods for Multi-class Support Vector Machines.” *IEEE Transactions on Neural Networks*，13(2):415–425，2002。[作者提供的 PDF](https://www.csie.ntu.edu.tw/~cjlin/papers/multisvm.pdf)。本地文件：`local-pdf/multisvm.pdf`（26 页，作者稿）。该文讨论 OVO/OVR 支持向量机的比较与投票规则；未查到该 PDF 的公开再分发许可。
3. **OVR 对照研究：** Ryan Rifkin 与 Aldebaro Klautau. “In Defense of One-Vs-All Classification.” *Journal of Machine Learning Research*，5:101–141，2004。[期刊页面](https://www.jmlr.org/papers/v5/rifkin04a.html) · [论文 PDF](https://www.jmlr.org/papers/volume5/rifkin04a/rifkin04a.pdf)。本地文件：`local-pdf/rifkin04a.pdf`（41 页，期刊版）。该文关于充分调参后 OVR 性能的结果，为两种方法使用一致的调参方案提供依据。该文件的公开再分发条款未在本项目中确认。

**数据与代码：** [作者实验代码包](https://www.csie.ntu.edu.tw/~cjlin/papers/ovo-ovr/)的下载清单包含 `segment.scale` 和 `vehicle.scale`。[LIBSVM 多分类数据页面](https://www.csie.ntu.edu.tw/~cjlin/libsvmtools/datasets/multiclass.html)记载：Segment 有 2,310 个样本、7 类、19 个特征；Vehicle 有 846 个样本、4 类、18 个特征。这两个文件已预先缩放，原始来源与转换信息见该数据页面。
