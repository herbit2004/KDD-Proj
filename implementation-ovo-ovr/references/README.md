# References

1. **Main paper:** Kuan-Ting Chen and Chih-Jen Lin. “Revisiting One-Versus-One and One-Versus-Rest: Insights into Imbalanced Multi-class Classification.” *IEEE International Conference on Data Mining (ICDM)*, 2025. [Author paper and code page](https://www.csie.ntu.edu.tw/~cjlin/papers/ovo-ovr/) · [PDF](https://www.csie.ntu.edu.tw/~cjlin/papers/ovo-ovr/OVO-OVR.pdf). Local file: `local-pdf/OVO-OVR.pdf` (9 pages). The author PDF has no explicit redistribution license; use the source link for public access.
2. **Method comparison:** Chih-Wei Hsu and Chih-Jen Lin. “A Comparison of Methods for Multi-class Support Vector Machines.” *IEEE Transactions on Neural Networks* 13(2):415–425, 2002. [Author-hosted PDF](https://www.csie.ntu.edu.tw/~cjlin/papers/multisvm.pdf). Local file: `local-pdf/multisvm.pdf` (26-page author manuscript). It defines the OVO/OVR SVM comparison and voting conventions. No public redistribution license was found for this PDF.
3. **Contrasting OVR evidence:** Ryan Rifkin and Aldebaro Klautau. “In Defense of One-Vs-All Classification.” *Journal of Machine Learning Research* 5:101–141, 2004. [Journal record](https://www.jmlr.org/papers/v5/rifkin04a.html) · [PDF](https://www.jmlr.org/papers/volume5/rifkin04a/rifkin04a.pdf). Local file: `local-pdf/rifkin04a.pdf` (41 pages, journal version). Its tuned-OVR result motivates careful parameter matching. The downloaded file was kept local because its exact redistribution terms were not established for this package.

**Data and implementation:** The [author's experiment archive](https://www.csie.ntu.edu.tw/~cjlin/papers/ovo-ovr/) lists `segment.scale` and `vehicle.scale` among its downloads. The [LIBSVM multiclass data page](https://www.csie.ntu.edu.tw/~cjlin/libsvmtools/datasets/multiclass.html) records Segment as 2,310 examples, seven classes, 19 features, and Vehicle as 846 examples, four classes, 18 features. These are pre-scaled files; the original sources and transformation are identified on that page.
