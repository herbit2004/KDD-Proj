# 参考文献与资源

1. **主论文：** Matthieu Latapy 与 Stephany Rajeh. “Trivial Graph Features and Classical Learning are Enough to Detect Random Anomalies.” *IEEE International Conference on Data Mining (ICDM)*，2025。DOI：[10.1109/ICDM65498.2025.00142](https://doi.org/10.1109/ICDM65498.2025.00142)。[arXiv 页面](https://arxiv.org/abs/2603.01841) · [论文 PDF](https://arxiv.org/pdf/2603.01841)。本地文件：`local-pdf/2603.01841v1.pdf`（10 页）。arXiv 页面标明 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)；公开目录 `public-pdf/` 保存了署名副本。
2. **相关研究：** Tim Poštuvan、Claas Grohnfeldt、Michele Russo 与 Giulio Lovisotto. “Learning-Based Link Anomaly Detection in Continuous-Time Dynamic Graphs.” *Transactions on Machine Learning Research*，2024。[arXiv 页面](https://arxiv.org/abs/2405.18050) · [PDF](https://arxiv.org/pdf/2405.18050)。本地文件：`local-pdf/2405.18050v2.pdf`（25 页）。该文讨论连续时间动态图中的链接异常检测；未确认该 PDF 的公开再分发许可。
3. **突发异常对照：** Siddharth Bhatia、Bryan Hooi、Minji Yoon、Kijung Shin 与 Christos Faloutsos. “MIDAS: Microcluster-Based Detector of Anomalies in Edge Streams.” *Proceedings of the AAAI Conference on Artificial Intelligence*，34(04):3242–3249，2020。DOI：[10.1609/aaai.v34i04.5724](https://doi.org/10.1609/aaai.v34i04.5724)。[会议页面](https://ojs.aaai.org/index.php/AAAI/article/view/5724) · [PDF](https://ojs.aaai.org/index.php/AAAI/article/download/5724/5580)。本地文件：`local-pdf/MIDAS-AAAI20.pdf`（8 页）。该文提供边流微簇和时间突发异常的对照方法；未确认该 PDF 的公开再分发许可。
