# 参考文献与资源

1. **主论文：** Pernille Matthews、Lena Krieger、Tommaso Amico、**Arthur Zimek**、Thomas Seidl 与 Ira Assent. “ExDBSCAN: Explaining DBSCAN with Counterfactual Reasoning.” *Proceedings of the 32nd ACM SIGKDD Conference on Knowledge Discovery and Data Mining V.2 (KDD ’26)*，2026，12 页。DOI：[10.1145/3770855.3817692](https://doi.org/10.1145/3770855.3817692)。[Canvas 课程 PDF](https://canvas.ust.hk/courses/72132/files/12588624?wrap=1)（须登录）。PDF 首页标明 CC BY 4.0。本地尚无正文 PDF；目前通过 Canvas 阅读。
2. **补充材料：** Pernille Matthews、Lena Krieger、Tommaso Amico、**Artur Zimek**、Thomas Seidl 与 Ira Assent. “ExDBSCAN: Explaining DBSCAN with Counterfactual Reasoning — Additional Material.” arXiv:2605.30225，第 2 版，2026。[arXiv 页面](https://arxiv.org/abs/2605.30225) · [PDF](https://arxiv.org/pdf/2605.30225)。本地文件：`local-pdf/2605.30225v2.pdf`（24 页）。包含伪代码和扩展实验，与 KDD 正文是两份独立文档。arXiv 页面未标明允许公开再分发该 PDF。
3. **算法基础：** Martin Ester、Hans-Peter Kriegel、Jörg Sander 与 Xiaowei Xu. “A Density-Based Algorithm for Discovering Clusters in Large Spatial Databases with Noise.” *Second International Conference on Knowledge Discovery and Data Mining*，226–231 页，1996。[AAAI 会议 PDF](https://cdn.aaai.org/KDD/1996/KDD96-037.pdf)。本地文件：`local-pdf/KDD96-037.pdf`（6 页）。该文定义核心点、密度可达和噪声；PDF 标明 AAAI 保留所有权利，因此文件仅保存在本地。
4. **反事实方法参照：** Piotr Romashov、Martin Gjoreski、Kacper Sokol、Maria Vanina Martinez 与 Marc Langheinrich. “BayCon: Model-agnostic Bayesian Counterfactual Generator.” *Proceedings of IJCAI*，740–746 页，2022。DOI：[10.24963/ijcai.2022/104](https://doi.org/10.24963/ijcai.2022/104)。[会议 PDF](https://www.ijcai.org/proceedings/2022/0104.pdf)。本地文件：`local-pdf/BayCon-IJCAI22.pdf`（7 页）。该文提供通用反事实搜索参照，用于理解 ExDBSCAN 的密度感知设计；未确认该 PDF 的公开再分发许可。

**代码与数据：** [ExDBSCAN 作者仓库](https://github.com/tommasoamico/ExDBSCAN)公开了源码，但核查时未发现许可文件。公开基准数据可从 [OpenML](https://www.openml.org/) 或 [UCI](https://archive.ics.uci.edu/)获取；选定的数据集和预处理步骤将在实验中记录。

**版本差异：** Canvas 推荐清单列出五位作者；课程提供的 KDD 正文 PDF 列出六位，包括 Lena Krieger。KDD 正文将第四位作者的名字拼为 “Arthur”，arXiv 补充材料则拼为 “Artur”。上述引文分别遵循对应文档。
