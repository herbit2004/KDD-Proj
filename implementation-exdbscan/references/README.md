# References

1. **Main paper:** Pernille Matthews, Lena Krieger, Tommaso Amico, Artur Zimek, Thomas Seidl, and Ira Assent. “ExDBSCAN: Explaining DBSCAN with Counterfactual Reasoning.” *Proceedings of the 32nd ACM SIGKDD Conference on Knowledge Discovery and Data Mining V.2 (KDD ’26)*, 2026, 12 pages. DOI: [10.1145/3770855.3817692](https://doi.org/10.1145/3770855.3817692). [Course PDF](https://canvas.ust.hk/courses/72132/files/12588624?wrap=1) (login required). The first page states **CC BY 4.0** and gives the full six-author ACM citation. The paper has been read in the Canvas preview, but the exact PDF has **not yet been saved** under `local-pdf/` because Canvas's download endpoint was blocked during this collection; no local/public copy is claimed.
2. **Additional material:** Pernille Matthews, Lena Krieger, Tommaso Amico, Artur Zimek, Thomas Seidl, and Ira Assent. “ExDBSCAN: Explaining DBSCAN with Counterfactual Reasoning — Additional Material.” arXiv:2605.30225, v2, 2026. [arXiv record](https://arxiv.org/abs/2605.30225) · [PDF](https://arxiv.org/pdf/2605.30225). Local file: `local-pdf/2605.30225v2.pdf` (24 pages). This is **not the KDD main paper**; it includes supporting method detail and extra experiments. The arXiv record's non-exclusive distribution license does not grant public PDF redistribution rights, so the local copy is not pushed.
3. **Algorithm foundation:** Martin Ester, Hans-Peter Kriegel, Jörg Sander, and Xiaowei Xu. “A Density-Based Algorithm for Discovering Clusters in Large Spatial Databases with Noise.” *Second International Conference on Knowledge Discovery and Data Mining*, pp. 226–231, 1996. [AAAI proceedings PDF](https://cdn.aaai.org/KDD/1996/KDD96-037.pdf). Local file: `local-pdf/KDD96-037.pdf` (6 pages). This paper defines core points, density reachability, and noise. The PDF says AAAI all rights reserved; it remains local.
4. **Counterfactual comparator:** Piotr Romashov, Martin Gjoreski, Kacper Sokol, Maria Vanina Martinez, and Marc Langheinrich. “BayCon: Model-agnostic Bayesian Counterfactual Generator.” *Proceedings of IJCAI*, pp. 740–746, 2022. DOI: [10.24963/ijcai.2022/104](https://doi.org/10.24963/ijcai.2022/104). [Proceedings PDF](https://www.ijcai.org/proceedings/2022/0104.pdf). Local file: `local-pdf/BayCon-IJCAI22.pdf` (7 pages). It frames generic counterfactual search against ExDBSCAN's density-aware method. No redistribution permission was confirmed for this PDF.

Implementation: [author GitHub repository](https://github.com/tommasoamico/ExDBSCAN). The repository's code is publicly visible, but no license file was found during this review. Public benchmark data may be obtained through [OpenML](https://www.openml.org/) or [UCI](https://archive.ics.uci.edu/); dataset selection and exact preprocessing will be recorded with the experiments.
