# I2｜ExDBSCAN 反事实聚类解释

**类型：** Implementation · **课程方向：** clustering / explainable data mining · **主论文：** Matthews et al., KDD 2026，见 [文献目录](references/README.md)。

## 研究内容与复现边界

DBSCAN 会把点归到密度簇或噪声，但“怎样最小改变一个点使其被分到另一簇”并不容易回答，因为移动一个点也可能改变密度连接关系。ExDBSCAN 构造满足聚类结果条件的反事实解释，并比较解释的有效性、距离和多样性。本项目先重现二维可视化，再在两份小型公开表格数据上比较原方法与简单反事实搜索基线。实验限定单点变化和论文实现支持的数值特征；不承诺覆盖全部 30 个论文基准。

## 实验设计与产出

在合成双月形/多密度数据上做边界和噪声点的案例图，之后在公开表格数据上选择稳定的 DBSCAN 参数。每份数据固定若干已聚类查询点，测量解释有效率、欧氏或标准化距离、不同解释之间的多样性、运行时间；同时给出失败率和约束不满足的例子。基线包括随机搜索、最近目标簇点方向搜索，以及原论文可实现的对照。必须明确“使当前点改类”与“重新运行 DBSCAN 后全局结构改变”的判定规则。交付可重复的配置、图表和案例。
